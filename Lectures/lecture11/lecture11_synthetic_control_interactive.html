Block 1

Identification

One treated unit

  • One unit, treated at a known date
  • Several untreated units
  • Target: the path of effects for that unit

Abadie and Gardeazabal (2003): ETA terrorism and Basque GDP. Donors: 16 other Spanish regions.

Setup

Abadie, Diamond, and Hainmueller (ADH 2010):

  • Units \(j \in \{1, \dots, J+1\}\), periods \(t \in \{1, \dots, T\}\)
  • \(Y_{jt} = Y_{jt}(0) + D_{jt}\tau_{jt}\)
  • Unit 1 treated: \(D_{1t} = \mathbf{1}\{t > T_0\}\)
  • Donors: \(D_{jt} = 0\) for all \(t\), \(j \geq 2\)

Target, for \(t > T_0\):

\[ \tau_{1t} = Y_{1t} - \underbrace{Y_{1t}(0)}_{\text{unobserved}} \]

Factor model

\[ Y_{jt}(0) = \delta_t + \theta_t X_j + \lambda_t \mu_j + \varepsilon_{jt} \]
TermVaries overMeaning
\(\delta_t\)\(t\)common shock (a scalar)
\(\lambda_t\) (factor)\(t\)\(R\) shared shocks
\(\mu_j\) (loading)\(j\)exposure to each factor, fixed over time
\(X_j\), \(\theta_t\)\(j\); \(t\)observed covariates; their coefficients (not loadings)
\(\varepsilon_{jt}\)\(j\), \(t\)idiosyncratic shock

\(R\) is the number of factors, not units.

\(\lambda_t = \lambda\) and \(\theta_t = \theta\): unit FE, parallel trends.

Otherwise units load differently on common shocks. Requires \(T_0 > R\).

Factors and loadings: an example

States, unemployment, one factor (\(R = 1\)).

\[ Y_{jt}(0) = \delta_t + \lambda_t \mu_j + \varepsilon_{jt} \]
  • Factor \(\lambda_t\): the national manufacturing cycle. One number per year, the same for every state.
  • Loading \(\mu_j\): a state's exposure. Michigan: large. Massachusetts: small.
  • Shock \(\varepsilon_{jt}\): anything else hitting one state in one year.

Michigan is treated. Service states fail: they barely move when the cycle turns. We need \(\sum_j w_j \mu_j = \mu_1\). Ohio and Indiana work. So do loadings 2 and 0 with weights \((\tfrac12, \tfrac12)\).

If the weighted donors track Michigan through booms and busts, the exposures likely match.

What is \(R\), and why \(T_0 > R\)?

  • Counting: \(R\) unknown loadings per unit, \(T_0\) observations. Need \(T_0 > R\).
  • \(R\) is assumed. Classic SC never estimates it.
  • Rough check: scree plot of the donor outcome matrix, or Bai and Ng criteria.
  • Estimate \(R\): Xu's GSC, matrix completion.

DiD vs. the factor model

DiDFactor model
\(Y_{jt}(0)\)\(\delta_t + \alpha_j\)\(\delta_t + \theta_t X_j + \lambda_t \mu_j + \varepsilon_{jt}\)
Unit part\(\alpha_j\), constant effect\(\lambda_t \mu_j\), effect varies with \(t\)

If \(\lambda_t = \lambda\) and \(\theta_t = \theta\): \(\theta X_j + \lambda \mu_j = \alpha_j\). This is parallel trends.

\[ \big[ Y_{1t}(0) - Y_{1s}(0) \big] - \frac{1}{J} \sum_{j=2}^{J+1} \big[ Y_{jt}(0) - Y_{js}(0) \big] = (\lambda_t - \lambda_s) \Big( \mu_1 - \frac{1}{J} \sum_{j=2}^{J+1} \mu_j \Big) \]

(ignoring \(\varepsilon\) and \(X\)). Fails when the factor moves and \(\mu_1\) is not the donor mean.

Balancing weights

Unit 1 is treated; donors are \(j = 2, \dots, J+1\). Every sum over \(j\) below runs over donors. Weights: \(w = (w_2, \dots, w_{J+1})\), \(w_j \geq 0\), \(\sum_{j=2}^{J+1} w_j = 1\).

Treated unit, untreated outcome:

\[ Y_{1t}(0) = \delta_t + \theta_t X_1 + \lambda_t \mu_1 + \varepsilon_{1t} \]

Weighted donors (using \(\sum_j w_j = 1\)):

\[ \sum_{j=2}^{J+1} w_j Y_{jt} = \delta_t + \theta_t \sum_{j=2}^{J+1} w_j X_j + \lambda_t \sum_{j=2}^{J+1} w_j \mu_j + \sum_{j=2}^{J+1} w_j \varepsilon_{jt} \]

The target is the gap between the two. We choose \(w\) so the pre-period gap is zero.

What cancels

Suppose for all \(t \leq T_0\): \(\sum_{j=2}^{J+1} w_j Y_{jt} = Y_{1t}\) and \(\sum_{j=2}^{J+1} w_j X_j = X_1\). Subtract:

\[ Y_{1t}(0) - \sum_{j=2}^{J+1} w_j Y_{jt} = \theta_t \Big( X_1 - \sum_j w_j X_j \Big) + \lambda_t \Big( \mu_1 - \sum_j w_j \mu_j \Big) + \Big( \varepsilon_{1t} - \sum_j w_j \varepsilon_{jt} \Big) \]
  • \(\delta_t\) cancels: common to all units, weights sum to one
  • \(X\) term is zero
  • \(\mu\) term balances only approximately: the fit is on \(Y\), which includes \(\varepsilon\)

Bias bound

With exact fit and \(T_0 > R\), for \(t > T_0\):

\[ Y_{1t}(0) - \sum_{j=2}^{J+1} w_j Y_{jt} = \sum_{j=2}^{J+1} w_j \sum_{s=1}^{T_0} \psi_{st} (\varepsilon_{js} - \varepsilon_{1s}) - \sum_{j=2}^{J+1} w_j (\varepsilon_{jt} - \varepsilon_{1t}) \] \[ \psi_{st} = \lambda_t \Big( \sum_{n=1}^{T_0} \lambda_n' \lambda_n \Big)^{-1} \lambda_s' \]

\(s \leq T_0\): pre-periods. \(t > T_0\): the post-period. Each \(\varepsilon\) difference is donor minus treated.

  • First term: pre-period noise, correlated with \(w\). Shrinks as \(T_0\) grows
  • Second term: post-period noise, mean zero. Does not shrink
  • Bound grows with \(J\) and \(R\) (Abadie 2021)

Block 2

Estimation

The estimator

For \(t > T_0\):

\[ \hat\tau_{1t} = Y_{1t} - \sum_{j=2}^{J+1} \hat w_j Y_{jt} \]

Exact balance requires \((Y_{11}, \dots, Y_{1T_0}, X_1)\) in the convex hull of the donors.

Otherwise minimize imbalance.

Two hulls. Identification needs \(\mu_1\) in the hull of the loadings (unobserved). The condition above is in observed outcomes (checkable). Outcomes inside and loadings outside is the dangerous case: the fit looks fine.

Choosing \(w\) and \(V\)

\(\mathbf{X}_1\), \(\mathbf{X}_0\): \(K\) predictors, including pre-period outcome summaries.

\[ \hat w(V) = \arg\min_{w \in \Delta} \sum_{k=1}^{K} v_k \Big( X_{1k} - \sum_{j=2}^{J+1} w_j X_{jk} \Big)^2 \]

\(V = \text{diag}(v_k)\) penalizes mismatch per predictor. Only \(\hat w\) is used. Choosing \(V\):

  1. For each \(V\), solve for \(\hat w(V)\)
  2. Score by pre-period MSPE (ADH 2010) or validation error (ADH 2015)
  3. Search over \(V\) (non-convex)

Block 3

Inference

The problem

  • Trends treated as fixed
  • Uncertainty: error in the approximation of \(Y_{1t}(0)\)
  • \(N_1 = 1\): no averaging over treated units

Placebo test

ADH (2010): apply SC to each donor as if treated.

\[ r_j = \frac{\text{RMSPE}_j(T_0 + 1, \dots, T)}{\text{RMSPE}_j(1, \dots, T_0)}, \qquad p = \frac{1}{J+1} \sum_{j=1}^{J+1} \mathbf{1}\{r_j \geq r_1\} \]

\(r_j\): post-period RMSPE over pre-period RMSPE.

  • Exact under exchangeable assignment
  • Minimum \(p\): \(1/(J+1)\)

Placebos: Basque Country

Basque series are not embedded yet.

\(p = 0.35\). Minimum possible: \(1/17 \approx 0.059\). Basque Country stays in each placebo pool, as in ADH.

Placebos: simulation live

Added for class: the same test on the simulated panel, where the truth is known. All \(J+1 = 31\) units are treated in turn.

Hahn and Shi (2017)

  • Symmetry: with no effect, \(r_1\) and each \(r_j\) have the same distribution
  • Sampling view: units are draws, so symmetry generally fails and size is distorted
  • Randomization view (Abadie): symmetry holds if assignment is uniform

What is the \(p\)-value about: assignment, or sampling?

Firpo and Possebom (2018)

  • Placebo test: uniform assignment across units
  • Parametric family of assignment probabilities; uniform is a special case
  • Sensitivity of the decision to departures from uniform

The \(p\)-value weights units by assumed assignment probabilities. A parameter \(\phi\) tilts them; \(\phi = 0\) is uniform. Report \(p\) as \(\phi\) varies.

Like a propensity score, but posited, not estimated.

Conformal: Chernozhukov, Wüthrich, and Zhu (2021)

Under the sharp null \(\tau_{1t} = 0\): fit on all periods, residuals \(\hat u_t = Y_{1t} - \hat Y_{1t}(0)\).

\[ S_q(\hat u) = \Big( \frac{1}{\sqrt{T - T_0}} \sum_{t > T_0} |\hat u_t|^q \Big)^{1/q} \]
  • \(q = \infty\): large transient effects; \(q = 1, 2\): persistent effects
  • iid permutations: exact under exchangeability of \(\{u_t\}\)
  • Moving blocks: stationarity and weak dependence
  • Works with DiD, SC, constrained Lasso, factor models, matrix completion
  • CIs by test inversion
  • Ignores weight estimation error (Cattaneo et al. 2021)

Conformal, step by step

  1. Impose the sharp null \(\tau_{1t} = 0\)
  2. Fit on all periods; get residuals \(\hat u_t\)
  3. Compute \(S_q\) on the post-period residuals
  4. Reshuffle time (iid or moving blocks); recompute \(S_q\)
  5. \(p\) = share of reshuffled \(S_q\) at least as large as observed
  6. CI: invert the test over \(\tau_0\)

Conformal test: simulation live

Added for class. Sharp null \(\tau_{1t} = 0\), SC fit on all 40 periods, moving-block (cyclic shift) permutations, so the smallest possible \(p\) is \(1/T = 0.025\). Illustration only, not the full CWZ procedure.

Block 4

Failure modes and practice

Dormant factors live

Hollingsworth and Wing (2022): factors collinear before \(T_0\), distinct after. Treated \(\mu = (1, 0)\).

Dormant factors: an example

  • Before \(T_0\), one factor drives unemployment: the manufacturing cycle \(\lambda_{1t}\)
  • After \(T_0\), oil prices crash: \(\lambda_{2t}\), which barely moved before
  • Exposure \(\mu_{j2}\): little in Michigan, a lot in Texas

The weights pick Ohio, Indiana, and Texas: they tracked Michigan before \(T_0\). Nothing revealed Texas's oil exposure. After the crash, synthetic Michigan jumps, and the gap looks like a policy effect.

Fix: choose donors on substance, for example exclude oil states. The simulation above is the same problem: weighted loadings \((0.80, 0.20)\) vs. treated \((1, 0)\).

Imperfect fit

Ferman and Pinto (2021). Without exact fit, \(\hat w\) trades off:

  • Matching loadings
  • Minimizing variance of weighted shocks
  • \(\hat w\) does not recover the loadings, even as \(T_0 \to \infty\)
  • Biased if assignment is correlated with the factors

Demeaned SC (add an intercept):

  • Can improve on DiD in bias and variance
  • Still biased under selection on time-varying factors

Non-unique \(W\)

Abadie and L'Hour (2021):

  • Inside the hull: many \(w\) with the same fit. A \(K\)-dimensional hull needs only \(K+1\) donors. On a line: donors at 0 and 2, or at 0.5 and 1.5, both match 1
  • Different \(w\), different post-period estimates
  • Near the boundary: corner solution, few donors

Donor pool and covariates

Abadie (2021):

  1. Exclude similar interventions. Donors must be unaffected.
  2. Exclude large idiosyncratic shocks. They add noise to \(\sum_j w_j \varepsilon_{jt}\), and weights may fit it.
  3. Small, curated pool.
    • Bound grows with \(J\)
    • More donors: more overfitting
    • Averaging dissimilar donors: interpolation bias
    • More donors: non-unique \(W\)

Covariates and multiple outcomes

  1. Include relevant covariates. Omitted \(X_j\) go into \(\mu_j\): larger \(R\), larger bound.
  2. Multiple outcomes (Sun, Ben-Michael, and Feller 2025).
    • Separate weights per outcome overfit
    • One common \(w\): stack the outcomes, or average them
    • Noise averages out, shared signal does not
    • Needs shared factors: check low rank

Outcome vs. covariate

  • Covariate: unaffected by treatment. Matched, not a target.
  • Outcome: may be affected. Pre-period path matched; post-period effect is a target.
  • Test: could treatment change it after \(T_0\)? Then it is an outcome.

Augmented SCM

Ben-Michael, Feller, and Rothstein (2021). Bias correction, as in matching (L3):

\[ \hat Y_{1T}^{\text{aug}}(0) = \sum_{j=2}^{J+1} \hat w_j Y_{jT} + \Big( \hat m_{1T} - \sum_{j=2}^{J+1} \hat w_j \hat m_{jT} \Big) \]

\(\hat m\): outcome model on pre-period outcomes. Ridge ASCM:

\[ \hat w_j^{\text{aug}} = \hat w_j + (X_1 - X_0' \hat w)' (X_0' X_0 + \kappa I)^{-1} X_j \]
  • \(X_j\) centered; \(\kappa\) sets the extrapolation
  • Negative weights allowed
  • Good fit: \(\hat m\) correction small, ASCM \(\approx\) SCM

Block 5

Many treated units

Matrix view

\[ Y(0) = \begin{pmatrix} Y_{co,pre}(0) & Y_{co,post}(0) \\ Y_{tr,pre}(0) & \textbf{?} \end{pmatrix} \] \[ \text{ATT} = \frac{1}{N_1} \sum_{it: D_{it} = 1} \big( Y_{it} - \hat Y_{it}(0) \big) \]

Fit on untreated cells, impute ?, average (L9). Methods differ in the model for \(\hat Y_{it}(0)\).

Interactive FE: Xu (2017)

\[ Y_{it}(0) = X_{it}' \beta + \alpha_i + \xi_t + \mu_i' \lambda_t + \varepsilon_{it} \]

Generalized synthetic control:

  1. Controls only (Bai 2009), alternate until convergence:
    • Given \(\hat\beta\): remove \(\alpha_i, \xi_t\) from \(Y - X\hat\beta\); the top \(R\) principal components give \(\hat\lambda_t\), and regressing each control on them gives \(\hat\mu_j\)
    • Given \(\hat\lambda_t, \hat\mu_j\): update \(\hat\beta\) by OLS
  2. Each treated unit: regress its pre-period \(Y_{it} - X_{it}'\hat\beta - \hat\xi_t\) on \(\hat\lambda_t\), with an intercept, to get \(\hat\alpha_i, \hat\mu_i\)
  3. Impute: \(\hat Y_{it}(0) = X_{it}'\hat\beta + \hat\alpha_i + \hat\xi_t + \hat\mu_i'\hat\lambda_t\)
  • \(R\) by cross-validation; a scree plot is a rough check (next slide)
  • Consistent as \(N_{co}, T_0 \to \infty\); suggested \(N_{co} \geq 40\), \(T_0 \geq 10\)
  • Strict exogeneity of \(X_{it}\)

Why we can estimate the factors here

  • Classic SC: one treated unit, few donors. Too little to learn \(\lambda_t\), so it matches outcomes with weights instead.
  • GSC: many controls and a long pre-period. Learn \(\lambda_t\) from the controls, then \(\mu_i\) from the treated unit's pre-period.

SCM with staggered adoption

Ben-Michael, Feller, and Rothstein (2022). Treated unit \(j\), imbalance \(q_j\):

  • \(q^{sep}\): root mean of \(q_j^2\)
  • \(q^{pool}\): imbalance of the average pre-period gap
\[ \min_{\Gamma} \; \nu (\tilde q^{pool})^2 + (1 - \nu)(\tilde q^{sep})^2 + \kappa \|\Gamma\|_F^2 \]
  • \(\nu = 0\): separate; \(\nu = 1\): pooled
  • With intercept: weighted DiD

Synthetic DiD: Arkhangelsky et al. (2021)

\[ \hat\tau^{sdid} = \arg\min_{\tau, \alpha, \xi, m} \sum_{i, t} (Y_{it} - m - \alpha_i - \xi_t - D_{it} \tau)^2 \, \hat\omega_i \hat\phi_t \]
\(\alpha_i\)Unit weightsTime weights
DiDyesuniformuniform
SCno\(\hat\omega_i\)none
SDIDyes\(\hat\omega_i\)\(\hat\phi_t\)
  • \(\hat\omega_i\): regularized toward uniform
  • \(\hat\phi_t\): pre-periods that predict the post-period among controls
  • Either set removes bias: approximately unbiased
  • Inference: placebo, jackknife, block bootstrap

Summary

  • SC: weights balancing a factor model in pre-period outcomes
  • Good fit is necessary, not sufficient (dormant factors)
  • Outside the hull: SC fails; augmentation extrapolates
  • Inference: placebos, conformal, intervals. One treated unit, strong assumptions
  • Many units: same imputation, different \(Y(0)\) models
